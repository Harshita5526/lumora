# LUMORA

A responsive landing page for a fictional creative studio, built as my first web development project using only HTML and CSS.

**Live demo:** https://harshita5526.github.io/lumora/

## Features

- Sticky navbar with a blur effect and animated link hover
- Hero section with a circular image, floating icons and a fade-in intro
- Inspiration cards with hover effects (lift, glow and image zoom)
- Fully responsive for desktop, tablet and mobile
- Smooth scrolling between sections
- Keyboard focus styles and reduced-motion support

## Built with

- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries, animations)

## What I learned

- Building layouts with Flexbox and Grid
- Using CSS variables to keep colors consistent
- Making a design responsive across screen sizes
- Writing hover effects and keyframe animations

## Run it locally

1. Clone the repo: `git clone https://github.com/Harshita5526/lumora.git`
2. Open the folder and double-click `index.html`
